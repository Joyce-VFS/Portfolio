The Vigenère cipher is a method of encrypting messages using a code word, or key, to substitute letters in the plaintext with other letters in the alphabet. 
The resulting ciphertext looks like random letters, but can be deciphered if the key is known. 
It has the alphabet written out 26 times in different rows, each alphabet shifted cyclically to the left compared to the previous alphabet, 
corresponding to the 26 possible Caesar ciphers.
At different points in the encryption process, the cipher uses a different alphabet from one of the rows.
